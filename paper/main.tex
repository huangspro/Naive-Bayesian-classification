	\section{Abstract}
	
	Machine classification is an important area of machine learning, aiming to classify samples based on their input features. A classification model can be expressed as
	$\hat{y} = model(X)$, where $X \in \mathbb{R}^n$.
	The training set is used to determine the model parameters, while the test set is used to evaluate the model's performance. Various classification algorithms have been developed, including decision trees, SVMs, and others.
	
	This paper investigates Naive Bayes Classification (NB) and compares it with other classification methods. A direct implementation of NB may suffer from the curse of dimensionality, which can significantly degrade its performance and even render it ineffective. This issue arises because $P(c)$ or $P(x)$ may become zero when the dataset contains no corresponding samples, potentially leading to incorrect class predictions.
	
	This report investigates how to mitigate the curse of dimensionality and improve the effectiveness of NB. The code of our project was stored on \textbf{\url{https://github.com/huangspro/Naive-Bayesian-classification}}
	
	
	\section{Extending Naive Bayes Classification}
	
	\subsection{High-dimensional NB}
	
	NB aims to calculate
	\[
	c = \arg\max_c P(c \mid x)
	= \arg\max_c P(x \mid c)P(c),
	\]
	where $x$ denotes the value of the input feature $X$, and $c$ refers to the class or label predicted by the model. To enhance its practical applicability, NB must be extended to handle high-dimensional feature spaces. Specifically,
	\[
	c = \arg\max_c P(c \mid x_1, x_2, \ldots)
	= \arg\max_c P(x_1, x_2, \ldots \mid c)P(c),
	\]
	where $x_1, x_2, \ldots$ denote the multidimensional input features
	$X = (x_1, x_2, \ldots)$.
	
	To calculate $P(x_1, x_2, \ldots \mid c)$, we introduce the independence assumption, which states that all input features $x_1, x_2, \ldots$ are conditionally independent given the class $c$. Accordingly,
	\begin{equation}
		\label{equ:p}
		P(x_1, x_2, \ldots \mid c)
		= \prod_{i=1}^{n} P(x_i \mid c).
	\end{equation}
	
	For each feature $x_i$, we search the dataset and count the number of entries, denoted by $N_{ic}$, in which the corresponding feature value and class label equal $x_i$ and $c$, respectively. The conditional probability is then estimated as
	\[
	P(x_i \mid c) = \frac{N_{ic}}{N_c}.
	\]
	
	
	\subsection{Laplace smoothing}
	
	To prevent $P(x_i \mid c)$ from becoming zero, Laplace smoothing (LS) is introduced. Instead of calculating $P(x_i \mid c) = \frac{N_{ic}}{N_c}$, Laplace smoothing adds a smoothing term to the numerator and adjusts the denominator accordingly:
	\[
	P(x_i \mid c)
	= \frac{N_{ic} + \alpha}{N_c + \alpha K},
	\]
	where $\alpha$ is the smoothing parameter and $K$ is the number of possible feature values.
	
	The rationale for using Laplace smoothing is that it is equivalent to adding $K$ entries to the dataset, with each entry representing one of the possible feature values.
	
	
	\section{Exploration on Real-World Data}
	
	\subsection{Modeling Continuous-Valued Data}
	
	Although discretization enables the Naive Bayes classifier (NB) to handle numerical features, real-world datasets often contain continuous-valued attributes. Discretization may result in information loss and introduce sensitivity to the selection of bin boundaries. To address these limitations, we extend the NB to continuous numerical data by adopting the Gaussian Naive Bayes (GNB) model.
	
	Specifically, GNB assumes that, conditioned on the class label, each continuous feature follows a Gaussian distribution. For a feature $x_i$ and class label $y=c$, the conditional probability density is defined as
	\begin{equation}
		p(x_i \mid y=c)
		=
		\frac{1}{\sqrt{2\pi\sigma_{ic}^{2}}}
		\exp\left(
		-\frac{(x_i-\mu_{ic})^2}{2\sigma_{ic}^{2}}
		\right),
	\end{equation}
	where $\mu_{ic}$ and $\sigma_{ic}^{2}$ denote the mean and variance of feature $x_i$ among the training instances belonging to class $c$, respectively.
	
	For each class $c$, the mean and variance of each continuous feature $x_i$ are estimated using the corresponding training samples. Specifically, the class-conditional mean and variance are calculated as
	\[
	\mu_{ic}=\frac{1}{N_c}\sum_{n:y_n=c}x_{ni},
	\]
	and
	\[
	\sigma_{ic}^{2}=\frac{1}{N_c}\sum_{n:y_n=c}(x_{ni}-\mu_{ic})^2,
	\]
	where $N_c$ denotes the number of training samples belonging to class $c$. These estimates are subsequently used to construct the Gaussian probability density for each feature conditioned on the class label.
	
	The class-specific means and variances are thus estimated directly from the training data. By modeling continuous features using Gaussian probability densities, GNB can process numerical attributes without requiring discretization. This provides a straightforward extension of NB for evaluating classification performance on real-world datasets.
	
	
	\subsection{Reconsidering the Independence Assumption}
	
	Our NB assumes that the features $x_i \in X$ are mutually independent. However, in real-world datasets, complex dependencies may exist among features. Specifically, a feature may be expressed as a function of other features:
	\[
	x_i = f(x_{k_1}, x_{k_2}, \ldots), \quad i \in [1,n],
	\]
	which may lead to
	\[
	P(x_i = k)
	= P(f(x_{k_1}, x_{k_2}, \ldots)=k)
	= P(x_{k_1}, x_{k_2}, \ldots).
	\]
	This suggests that the probability associated with $x_i$ may be dependent on the probabilities of the features from which it is derived. Consequently, including $P(x_i)$ in \autoref{equ:p} may result in redundant probability calculations. Such double counting may lead to overconfidence in the predicted probability of a particular class.

	\subsection{Method}
	To investigate the effect of training dataset size on classification accuracy (\autoref{tab:dataset1}), we trained the Naive Bayes (NB) classifier on BeanTrain and BeanTrain1000 and evaluated both models on BeanTest. The results are presented in \autoref{tab:test1}. The results suggest that a larger training dataset can improve classification accuracy. Furthermore, Laplace smoothing (LS) appears to be more beneficial when the training dataset is smaller. This may be attributed to the increased likelihood of observing feature values that are absent from a limited training sample, which can lead to zero probability estimates. By introducing a smoothing term, LS mitigates this issue and may therefore provide greater benefits when training data are scarce.

	\subsection{Evaluate Different Algorithms}

All models were evaluated on a test dataset containing 4,085 instances. In addition, we evaluated all methods on the raw dataset, in which the feature values remained continuous numerical data. 	\subsection{Model Selection and Parameters Setting}
		As shown in the results presented in \autoref{tab:classifier_comparison}, the Support Vector Machine (SVM) achieved the best overall performance among the classifiers evaluated. Therefore, SVM was selected as the final classification model, with data standardization adopted as the preprocessing method. Throughout the experiments, all classifiers were evaluated using the default hyperparameter settings provided by \texttt{scikit-learn}, without any additional hyperparameter tuning.
		
	\subsection{Analysis}
		The main reason for SVM outperforming NB is that SVM does not require the independence assumption, which contributes to its stronger adaptability to real-world data. In addition, kernel functions enable SVM to fit highly complex data distributions, while NB may fail to adapt due to its limited tunable parameters and naive independence assumption.
